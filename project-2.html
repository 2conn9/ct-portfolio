Project 2 Website

Overall, I think my project went well because I created a working digital clock that displays the time, date, day and current temperature on the LCD screen. One thing that went well was getting VSC and the Arduino to communicate with eachother. I learnt that my Python program gets the current time from the computer and gets the temperature from the Open-Meteo weather API. It then sends this information through the USB serial connection to the Arduino. The Arduino receives the information and displays it on the LCD screen. I also learned how to format information so that each part such as the time and temperature, appears in the correct position on the screen.

One of the difficult parts of the projects was getting the Arduino to read the information being sent from Python without errors. I had to make sure that the information was separated by commas so the Arduino could identify the time, date, day and temperature separately. Another difficult part was positioning the text on the screen. I had to use different coordinates and text sizes to make sure everything fit on the screen. I also had to learn how to centre the text instead of just choosing a fixed position.

During this project, I learned about how Python and Arduino can work together. I learned how serial communication allows the two programs to send information between each other. I also learned how an API can be used to get real world info, such as the current temperature, and use it in my own program. In addition, I improved my understanding of Arduino libraries, functions, variables and how information can be split into separate parts.

If I were to improve the project, I would add more features such as precipitation, a quote that changes every day or my timetable. Overall, I learned that programming often involves testing, finding problems and changing code until everything works properly.
